# actions and issues

Use this single log for project action items and issues.

## types

- `action` — work that must be completed.
- `issue` — a known problem, unresolved behavior, defect, or technical constraint.

## status values

`open` · `in progress` · `investigating` · `blocked` · `backlog` · `resolved` · `done`

`backlog` marks work that is accepted as needed but deliberately deferred, and which is not blocking current activity.
