The gross-fit gate

PASS

Runtime and hardware

Static HTML and inline SVG have effectively no service footprint. The core skill is Markdown guidance plus Python standard-library extractors and validators. PNG export adds Playwright/Chromium only at authoring time.

PASS

Authority boundary

No server, database, agent runtime, memory, or control plane is introduced. The plugin writes diagram artifacts; HX governance and repository documentation remain authoritative.

CONDITIONAL

Wiki delivery

Arbitrary HTML and scripts are commonly sanitized by wiki products. The project itself recommends PNG @2 for Confluence, Notion, and internal wikis. Wiki-native HTML cannot be assumed before platform selection.

Strengths that matter to HX

Real design discipline

The skill does more than recolor boxes: it limits focal accents, enforces orthogonal routing and complexity budgets, requires type-specific grammars, and instructs authors to delete or split when density is too high.

Destination-aware outputs

Format, canvas, detail, and audience are chosen before rendering. The distinction between engineer, mixed, and executive wording is particularly useful for HX inventories, reviews, and demos.

Accessibility and deterministic safety checks

Templates require role="img", resolving title/description IDs, and unique prefixes. A packaged standard-library self-check rejects remote assets beyond approved fonts, executable attributes, arbitrary scripts, and unsafe embedded content.

Useful migration bridge

Mermaid and draw.io importers parse text into an intermediate representation without rendering source JavaScript or following links. The documented fidelity ledger makes compression visible instead of silently pretending to preserve everything.

Risks and required HX controls

1 · “Self-contained” is qualified

All 104 shipped HTML assets reference Google Fonts. Layout still opens without the network, but typography may substitute. HX should vendor approved font files or standardize a system-font skin for offline, air-gapped, or immutable documentation.

2 · Main-only distribution

There are no versioned GitHub releases; the manifests say 2.4.0, while support follows latest main. HX should mirror and pin a reviewed commit/archive hash, then update through deliberate reviews—not floating auto-update.

3 · Wiki HTML is not portable

Do not make raw HTML embedding a wiki requirement. Publish PNG by default, retain HTML/SVG beside the source, and enable inline SVG only after a platform-specific sanitizer, CSP, accessibility, and dark-mode test.

4 · Generated truth can drift

A beautiful diagram can outlive the facts behind it. Every HX diagram should carry truth state, source references, generated timestamp, audience/detail settings, and—when imported—the fidelity ledger.

5 · Motion and networked onboarding expand risk

Static, script-free output should be mandatory unless motion is explicitly justified. URL-based brand extraction and icon regeneration should be maintainer-only activities; routine authors use the pinned HX profile and shipped icons.

6 · Tests are strong but not a release contract

The repository contains 9 test drivers, 8 verification drivers, a six-platform Python CI matrix, adversarial parser cases, geometry checks, and package gates. This review inspected them statically; it did not execute untrusted repository code.

Proposed HX operating contract

  1. One pinned HX profile. Maintain reviewed night-mode semantic tokens in HX source control; do not edit an auto-updated installed copy.
  2. Two lanes. Use Mermaid for compact, frequently edited technical diagrams. Use Diagram Design for architecture overviews, current-state maps, control boundaries, process/sequence explanations, executive views, and major HTML reports.
  3. Three artifacts when publishing. Keep the authoritative input or content brief, generated .html, and wiki-safe .png; retain .svg when vector reuse or accessibility benefits justify it.
  4. Mandatory provenance. Record tool commit/hash, diagram type, size, detail, audience, source references, truth state, and fidelity ledger.
  5. Static by default. No motion, remote scripts, iframe/embed/object, executable HTML attributes, or arbitrary remote assets.
  6. Review the meaning, not only the pixels. Human review must confirm topology, labels, omissions, and truth state before publication.
