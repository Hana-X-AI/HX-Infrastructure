8 · Not in plan v3, and still worth doing

Recommendation carried forward

Continuous integration. Every guarantee in this project is a manual run on one workstation. The regression suite, the P1-01 scanner and the validation records are all single manual executions; nothing re-runs them on push.

A reference-integrity check alone — every governance/… path cited in Markdown or HTML resolves to a file that exists — would have caught F-01 at the moment 52b76f9 was pushed, before any of the last three days of work. A filename-standards lint would have caught craig(1).md, That may be LoopX's strongest strat.md and phase Phase -2 before they entered the tree.

This is Transition Stage work, not Phase 3 — adding CI is new capability, not tightening. It belongs in the Gate B input set, and P-F1's design should account for it, because the authorization record that replaces the hard lock will have the same channel problem unless it is enforced at commit or CI time.
