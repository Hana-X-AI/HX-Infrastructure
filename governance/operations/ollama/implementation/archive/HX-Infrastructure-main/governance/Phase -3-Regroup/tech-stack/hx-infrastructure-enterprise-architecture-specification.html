Core Architectural Anchor: One Authority Per Concern
HX operates as a governed platform where each system concern has exactly one authoritative owner. Traffic routing belongs solely to OmniRoute; durable user/agent memory belongs to Mem0; stateful orchestration belongs to LangGraph with PostgreSQL; document intelligence belongs to Docling with Granite Docling 258M; and graph knowledge belongs to LightRAG. Shadow authorities, overlapping gateways, and premature container orchestrators are strictly eliminated.
