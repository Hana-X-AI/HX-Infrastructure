Source-storage model

Track

  • catalog.yaml and per-tech manifests
  • source URL, tag/commit, SHA-256, license, acquisition date
  • HX-authored distilled notes and indexes
  • verification tests and authoritative links

Keep local

  • full upstream repositories and release archives
  • large generated indexes and caches
  • transient worktrees
  • runtime model files and weights

Use a narrow ignore rule for library/technologies/**/sources/** and an idempotent native Bash sync | verify | status command. Fail the Agent Knowledge Base Review when required material is missing, mismatched, or stale. Avoid Git submodules initially.

Authority precedence to ratify

  1. Owner rulings and the constitution
  2. Canonical governance policies, contracts, registries, and accepted specifications
  3. Current measured evidence for runtime and host facts
  4. library/ source, indexes, and distilled knowledge
  5. Historical reports, handoffs, session notes, and chat transcripts

knowledge/instructions.md should encode this routing. On conflict, agents must surface the discrepancy; they must not silently choose the library.
