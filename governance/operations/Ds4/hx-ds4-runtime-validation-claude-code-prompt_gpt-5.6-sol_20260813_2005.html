DS4 PATTERN 1 — TOOL-CALL FIDELITY
Mine the principle, not DS4's DSML format.

DS4 demonstrates that:
- client JSON tool history may not serialize identically to the model's native tool syntax
- tool IDs can be critical to replay/continuation
- canonical re-rendering can be a fallback rather than proof of exact original representation

Turn this into HX contract tests:
- preserve tool ID
- preserve name
- preserve arguments semantically
- correlate result correctly
- preserve coherent next-turn history
- test streaming tool-call assembly if the client/runtime uses it

Do NOT make DSML an HX universal format.
