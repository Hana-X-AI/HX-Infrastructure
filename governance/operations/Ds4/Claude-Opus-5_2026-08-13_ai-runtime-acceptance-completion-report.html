3Pass 1 — the runtime acceptance layer

Contract

governance/policy/ai-runtime-acceptance-contract.md — 26 capabilities classified REQUIRED / OPTIONAL / PROFILE-SPECIFIC, test levels L0–L5, and the rule that does the real work: three evidence classes held strictly apart.

The contract names no host, no model and no runtime. Placement comes from the profile.

Offline harness

17 recorded fixtures and a PowerShell runner that asserts rather than reports. Coverage: identity, health, chat, SSE ordering and single termination, tool declaration, tool call identity, tool result correlation, multiple tool calls, malformed JSON, server error, cancellation cleanup, mid-stream error, reasoning separation, Anthropic messages and tool_use, 42,000-character payload serialization, and recovery after an error.

Proven failable

Corrupting the tool-correlation fixture turns T07 red and the runner exits non-zero: PASS: 17 FAIL: 1, exit 1. A suite that cannot fail is not a suite.

Fixtures return FIXTURE RESPONSE - NOT MODEL OUTPUT by design, so a fixture can never be mistaken for model output — the failure mode the source plan warned against.

4Pass 2 — hxs-3 placement overlay

hxs-3 durable role is unchanged

SERVER-REGISTRY.md says Agent intelligence. It still does. Zero registry changes were made and none was required — the registry never assigned DS4 to hxs-3, so there was no incorrect role to correct.

The host was also not restyled as "flexible development-model compute" or "experimental AI runtime node", which the placement plan's own wording invited. Document 1 forbids replacing an authoritative durable role with either phrase, and swapping one permanent mislabel for another would have missed the point. The System RAM row is a real finding, not paperwork

The smallest DS4 model variant documented in the reviewed snapshot targets 96/128 GB RAM machines. hxs-3 has 66 GB. That is evidence this workload, as documented, does not fit this host — not a gate to be waived. A smaller supported variant or a different host would have to be selected and re-gated.

No model download or runtime activation is authorized.

The gate also preserves the truth-state distinction the governance requires: discovery.md records hxs-3 as found with nouveau and no CUDA; driver-results.md records the later authorized driver install. The gate reads the as-built record and states which one it used.

5What DS4 contributed, and what was refused

Verified against the local source, not taken from the plan documents: 1,166 files; zero model weights; MIT licence with both the ds4.c and ggml copyright lines; the six /v1 endpoints including the Anthropic-compatible /v1/messages; disk KV checkpoint policy and tool-call mapping; Metal, CUDA and ROCm; the "around 25k tokens" Claude Code note verbatim; and ds4f-q2 documented for 96/128 GB machines.

One claim could not be re-verified: the snapshot zip is absent — only the extracted tree is present — so its SHA-256 e4e5a5ad… could not be recomputed. The extracted tree's own facts were checked directly instead.

Adopted as ideas, independently implemented

  • Evidence-class separation — protocol vs model behaviour vs performance.
  • The tool-call fidelity invariant: id, name and arguments survive, the result correlates to the same call, the next turn stays coherent.
  • Cold / warm / resume prefix distinctions, defined as live-only tests.
  • Separating fast protocol regression from model-backed quality testing.

Explicitly not adopted

  • No DS4 source copied. ds4-main is reference only, git-ignored, never vendored.
  • No ds4-agent as an HX orchestration framework.
  • No DSML as an HX universal tool format.
  • No model weights, no downloads, no DS4 installation.
  • No change to the vLLM/Qwen primary decision.
  • No Ansible, no security-hardening scope, no observability deployment, no distributed inference.

Because only ideas were reused and no code was copied, no MIT notice obligation is triggered. Had source been copied, the notice and source path would be recorded in the contract's provenance section — where the treatment is documented either way.
