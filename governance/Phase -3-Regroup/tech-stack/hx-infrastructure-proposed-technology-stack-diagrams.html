Scope: Governed, self-hosted AI application platform for development, testing, and demonstrations.
Executive Architectural Anchor: HX is structured across nine strictly separated planes. The stack adheres to the "One authority per concern" principle: one traffic plane (OmniRoute), one durable memory authority (Mem0), one relational state authority (PostgreSQL), one graph knowledge authority (LightRAG), and one fleet control standard (Bash/SSH over systemd).
