Phase 3 Remediation Plan — Deep · v2

Version 2 folds in ChatGPT/Codex's deep review of v1: five required corrections and seven improvements. Definition of done — two gates

Gate A — Remediation baseline complete. All P1 truth/control repairs pass their failable gates (P1-00…P1-06); P2-02, P2-05, P2-06 done; the expired-risk, tracker, and hxs-4 rulings recorded; C-01 preservation gate green. This is the reconciled-truth baseline.
Gate B — Future-implementation authorization ready. The OmniRoute charter, the P-F1 authorization-record design, the hxs-4 authority ruling, the named implementation phase (P-D0), and full-stack recon are complete, and C-02 is signed. Only Gate B can precede an implementation authorization — and even then that authorization is a separate, explicit owner act.

These two gates resolve the v1 contradiction (M-07): several owner rulings live in P2/P3, so "all rulings required" and "P2/P3 non-blocking" cannot both gate the same thing. Gate A is the truth baseline; Gate B is the decision readiness. P2/P3 hygiene items not named in Gate A are tracked, not blocking.
