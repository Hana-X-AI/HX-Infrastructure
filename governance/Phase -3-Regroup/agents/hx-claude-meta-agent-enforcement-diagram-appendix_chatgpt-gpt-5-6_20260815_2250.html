C. Mandatory Knowledge Base Review gate

The receipt is task- and run-bound evidence that required sources were actually reviewed.

D. Tool-call enforcement decision

Dynamic checks sit behind static capability boundaries.

Ordinary hook startup failure, invalid output and timeout are non-blocking. Critical controls require static permissions, tool deprivation, managed policy, a verified launcher or an Agent SDK callback boundary.

E. Failure classification and escalation

Only eligible failure classes receive one retry. Authority, knowledge and evidence failures stop immediately.

F. Control-plane protection hierarchy

H. Staged implementation and acceptance
